# Lexpeek

Translates text on the screen of a GNOME desktop: in a screen area, in the selected text or on the whole screen.

## Language

**Frozen screen**:
A screenshot of all monitors shown fullscreen in place of the desktop, in one mode at a time; another mode opens over the same screenshot.
_Avoid_: frame session, screen session

**Area translation**:
The frozen screen mode in which the user selects an area and gets the translation of its text with a dictionary article.
_Avoid_: area capture

**Whole screen translation**:
The frozen screen mode in which all text of the screen is shown translated in place of the original.
